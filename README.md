# SmartCart Segmentation System

## 📘 Overview
This project performs customer segmentation using clustering techniques (KMeans, Agglomerative Clustering) on SmartCart customer data.

### Features
- Data preprocessing (missing values, encoding, scaling)
- Feature engineering (spending, age, tenure)
- Dimensionality reduction with PCA
- Clustering (KMeans, Agglomerative)
- Cluster visualization and summary

### 🚫 Note
The dataset (`smartcart_customers.csv`) is **not included** in this repository.  
Please download it separately and place it in a folder like `getitmore/`.

### ⚙️ Requirements
- Python 3.x
- Libraries: pandas, numpy, matplotlib, seaborn, scikit-learn, kneed

### ▶️ How to Run
1. Clone the repository
2. Place your dataset in the `getitmore/` folder
3. Open `SmartCartSegmentationSystem.ipynb` in Jupyter Notebook
